🚀 DEPLOYMENT EN UBUNTU - PASOS RÁPIDOS
═══════════════════════════════════════════════════════════════

1️⃣  CONECTAR AL SERVIDOR:
   ssh tu-usuario@tu-servidor-ip

2️⃣  INSTALAR DOCKER (si no está instalado):
   curl -fsSL https://get.docker.com -o get-docker.sh
   sudo sh get-docker.sh
   sudo usermod -aG docker \$USER
   sudo apt install docker-compose-plugin -y

3️⃣  CLONAR EL REPOSITORIO:
   cd ~
   git clone https://github.com/Th3ProHero/rainbow-cake.git
   cd rainbow-cake

4️⃣  CONFIGURAR VARIABLES DE ENTORNO:
   cp .env.example .env
   nano .env
   
   ⚠️  IMPORTANTE - Cambiar estos valores:
   - AUTH_SECRET (32 caracteres random)
   - APP_URL=http://TU_IP:18473
   - ADMIN_SEED_PASSWORD (contraseña segura)
   - POSTGRES_PASSWORD (contraseña segura)

5️⃣  GENERAR SECRET:
   openssl rand -base64 32
   # Copiar resultado a AUTH_SECRET en .env

6️⃣  LEVANTAR LA APLICACIÓN:
   docker compose up -d --build

7️⃣  VER LOGS:
   docker compose logs -f

8️⃣  EJECUTAR MIGRACIONES Y SEED:
   docker compose exec app npx prisma migrate deploy
   docker compose exec app npx prisma db seed

9️⃣  ACCEDER A LA APP:
   http://TU_IP:18473/login
   
   📧 Email: admin@rainbowcakego.com
   🔑 Password: [tu ADMIN_SEED_PASSWORD]
